# Java 后端考核项目：和风天气接入开发引导

## 一、考核目标

实现一个 Java 后端服务，接入**和风天气（QWeather）**第三方 API，完成「根据用户输入的城市名称与行政区划，获取该地点当天实时天气」的功能。

本题可以配合ai解决，但是不能直接cv代码

你需要串联调用两个和风天气接口：

| 步骤 | 接口 | 作用 |
|------|------|------|
| 1 | [城市搜索（City Lookup）](https://dev.qweather.com/docs/api/geoapi/city-lookup/) | 通过 `location` 和 `adm` 查询城市，获取 `locationId` |
| 2 | [实时天气（Weather Now）](https://dev.qweather.com/docs/api/weather/weather-now/) | 通过 `locationId` 获取当天实时天气数据 |


推荐jdk版本在17及以上
本文档流程仅起辅助作用，详细信息见官方文档（https://dev.qweather.com/docs/）

## 二、整体调用流程

```

用户请求（location + adm）
    │
    ▼
城市搜索接口，HTTP 调用（RestTemplate）
(Geo API)
    │
    ▼
获取 LocationId（Gzip 解压）
    │
    ▼
实时天气接口，HTTP 调用（RestTemplate）
(Weather API)
    │
    ▼
返回天气信息（Gzip 解压）
    │
    ▼
封装结果返回前端
```

### 流程说明

1. **接收请求**：用户传入城市名（`location`）和上级行政区划（`adm`，用于排除重名城市）。
2. **城市搜索**：调用 `/geo/v2/city/lookup`，从返回的 `location` 列表中取出目标城市的 `id`（即 `locationId`）。
3. **实时天气**：将上一步得到的 `locationId` 作为参数，调用 `/v7/weather/now`。
4. **返回结果**：将天气信息（温度、天气状况、湿度、风力等）封装后返回。

### 3.2 城市搜索接口

- **请求路径**：`GET /geo/v2/city/lookup`
- **关键参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `location` | 是 | 城市名称，如 `北京`、`西安` |
| `adm` | 否 | 上级行政区划，用于排除重名，如 `黑龙江` |

- **请求示例**：

```http
GET https://your_api_host/geo/v2/city/lookup?location=西安&adm=黑龙江
Authorization: Bearer your_token
Accept-Encoding: gzip
```

- **关键返回字段**：

```json
{
  "code": "200",
  "location": [
    {
      "name": "西安",
      "id": "101050101",
      "adm1": "黑龙江省",
      "adm2": "牡丹江"
    }
  ]
}
```

从 `location` 数组中取第一个（或按业务规则筛选）元素的 `id`，作为下一步的 `locationId`。

### 3.3 实时天气接口

- **请求路径**：`GET /v7/weather/now`
- **关键参数**：

| 参数 | 必填 | 说明 |
|------|------|------|
| `location` | 是 | 城市搜索得到的 `locationId`，如 `101050101` |

- **请求示例**：

```http
GET https://your_api_host/v7/weather/now?location=101050101
Authorization: Bearer your_token
Accept-Encoding: gzip
```

- **关键返回字段**：

```json
{
  "code": "200",
  "now": {
    "obsTime": "2020-06-30T21:40+08:00",
    "temp": "24",
    "text": "多云",
    "humidity": "72",
    "windDir": "东南风",
    "windScale": "1"
  }
}
```
最后我们要求REST接口只返回`temp`和`text`字段


### 3.4 错误处理

和风天气使用 `code` 字段表示请求状态，`200` 表示成功。常见错误码：

| code | 含义 |
|------|------|
| 200 | 请求成功 |
| 400 | 请求错误，可能参数不正确 |
| 401 | 认证失败，请检查 Token |
| 404 | 查询的数据或地区不存在 |
| 429 | 超过访问次数限制 |

业务代码中需判断 `code` 是否为 `200`，并对异常情况进行合理处理与提示。(这里推荐直接使用try-catch)

## 四、各模块技术栈简要说明

### 4.1 技术栈

| 模块/环节 | 技术栈 | 用途 |
|-----------|--------|------|
| HTTP 客户端 | **RestTemplate** | 向和风天气 API 发送 GET 请求 |
| JSON 解析 | **Jackson** | 将 API 返回的 JSON 反序列化为 Java 对象 |
| 响应压缩 | **Gzip** | 解压和风天气默认的 Gzip 压缩响应体 |
| 配置管理 | **@ConfigurationProperties** | 读取 API Host、Token 等配置 |
| 统一响应 | 自定义 `Result<T>/Result` | 统一 API 返回格式 |

---

### 4.2 Spring Boot

**简介**：Spring Boot 是基于 Spring 框架的快速开发脚手架，通过自动配置和起步依赖，让你用很少的配置就能启动一个可运行的 Web 应用。

**在本项目中的用途**：

- 提供 `@RestController`、`@Service` 等注解，组织分层架构
- 通过 `application.yml` 管理和风天气的 API Host、Token
- 自动装配 Jackson、RestTemplate 等组件

**示例配置**（`application.yml`）：

```yaml
qweather:
  api-host: https://your_api_host
  token: your_token
```

本项目无需使用到数据库，因此在创建spring项目时无需勾选数据库的相关依赖

---

### 4.3 RestTemplate

**简介**：RestTemplate 是 Spring 提供的同步 HTTP 客户端，封装了常见的 HTTP 操作（GET、POST 等），支持将响应直接映射为 Java 对象。

**在本项目中的用途**：

- 向和风天气发送 GET 请求
- 在请求头中设置 `Authorization: Bearer xxx`
- 将响应体反序列化为 DTO 对象

**基本用法示例**：

<T> T execute(
    String url,
    HttpMethod method,//调用方式GET\POST等等（类似前端调用的几种方式）
    RequestCallback requestCallback,//请求发送前的处理，本题不需要使用
    ResponseExtractor<T> responseExtractor,//响应接收后的处理，本题需要调用Gzip解压方法
    Object... uriVariables//URL参数，当然这里可以不写，通过url拼接的方式在url中写明参数
)

以下是例子

```java
HttpHeaders headers = new HttpHeaders();
headers.set("Authorization", "Bearer " + jwt);
headers.set("Accept-Encoding", "gzip");


String url = "https//"+apiHost + "/geo/v2/city/lookup?location={location}&adm={adm}";

String transform=restTemplate.execute(geoApiUrl, HttpMethod.GET,
        request -> {
            request.getHeaders().putAll(headers);
            request.getHeaders().set("Accept-Encoding", "gzip");
        },
        new GzipResponseExtractor());
```

### 4.4 Gzip 压缩处理

**简介**：Gzip 是一种常用的数据压缩算法。和风天气 Web API **默认使用 Gzip 压缩响应体**，可显著减少网络传输量、加快请求速度。

**在本项目中的用途**：

- 请求时在 Header 中声明 `Accept-Encoding: gzip`，告知服务端可以接收压缩数据
- 收到响应后，需要对 `Content-Encoding: gzip` 的响应体进行**解压**，再交给 Jackson 解析





> 如果未正确处理 Gzip，你可能会收到乱码或解析失败。这是本考核的**重点考察点之一**。

### 4.5 @ConfigurationProperties

**简介**：Spring Boot 提供的类型安全配置绑定注解，可将 `application.yml` 中的配置项自动注入到 Java 类的字段中。

**在本项目中的用途**：

- 将 `qweather.api-host`、`qweather.token` 绑定到 `QWeatherProperties` 类
- 避免在代码中硬编码 API 地址和密钥

```java
@ConfigurationProperties(prefix = "qweather")
public class QWeatherProperties {
    private String apiHost;
    // getter / setter
}
```
如果这一步不会，你可以暂时先直接使用硬编码

## 五、开发步骤建议

### 步骤 1：初始化 Spring Boot 项目

- 使用 Spring Initializr 创建项目，依赖选择：`Spring Web`
- 在 `application.yml` 中配置和风天气的 API Host 

### 步骤 2：定义 DTO 与配置类

- 创建 `QWeatherProperties` 读取配置
- 创建 `CityLookupResponse`、`WeatherNowResponse` 映射第三方返回结构,或者直接使用String接收，之后通过`objectMapper`转化为`JsonNode`
- 创建 `WeatherVO` 作为对外返回的业务对象

### 步骤 3：配置 RestTemplate（含 Gzip 支持）

- 创建 `RestTemplateConfig`，注册支持 Gzip 解压的 `RestTemplate` Bean。如果你不熟悉springbean，也可以直接创建一个用于Gzip解压的工具类。
- 统一设置请求头（Authorization、Accept-Encoding）

### 步骤 4：封装 QWeatherClient

- 实现 `lookupCity(String location, String adm)` 方法
- 实现 `getWeatherNow(String locationId)` 方法
- 处理 HTTP 异常和 `code != 200` 的业务异常

### 步骤 5：实现 Service 

以下代码仅供逻辑参考

```java
public WeatherVO getTodayWeather(String location, String adm) {
    // 1. 城市搜索
    CityLookupResponse cityResponse = qWeatherClient.lookupCity(location, adm);
    if (cityResponse.getLocation() == null || cityResponse.getLocation().isEmpty()) {
        throw new QWeatherException("未找到匹配的城市");
    }
    String locationId = cityResponse.getLocation().get(0).getId();

    // 2. 获取实时天气
    WeatherNowResponse weatherResponse = qWeatherClient.getWeatherNow(locationId);

    // 3. 封装返回
    return WeatherVO.from(weatherResponse);
}
```

### 步骤 6：暴露 REST 接口

```java
@RestController
@RequestMapping("/api/weather")
public class WeatherController {

    @GetMapping("/now")
    public Result getTodayWeather(
            @RequestParam String location,
            @RequestParam(required = false) String adm) {
        WeatherVO weather = qWeatherService.getTodayWeather(location, adm);
        return Result.success(weather);
    }
}
```
